# Emails de primer contacto — Nueva Zelanda (v1)

20 variaciones para probar qué asunto y qué ángulo responden mejor. Se cargaron como borradores
en Gmail sin destinatario. Antes de enviar cada uno:

1. Completar `[Name]`, `[Business]` y `[Town]`; borrar o ajustar la frase sobre su web actual si no aplica.
2. Enviar uno por uno, solo a emails publicados por el propio negocio (su web o su ficha).
3. Mantener la línea final para darse de baja y respetarla siempre (ley de Nueva Zelanda,
   Unsolicited Electronic Messages Act 2007).
4. Anotar en la lista de prospectos qué variante se envió, para medir respuestas.

Demo: https://demo-tpn0fpa8.vercel.app (negocio ficticio de paving).

Firma común:

```
Tomas Blaha
Co-founder, DGB Works
Websites, content and automation for trade businesses
```
